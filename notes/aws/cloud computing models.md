##### Content
1. IaaS
	- Offers virtualized infra
	- Like **Amazon EC2, Azure Virtual Machines and Google Compute Engine**
2. PaaS
	- Cloud platform for dev, deploy and managing apps
	- Simplifies app dev
	- Like **AWS Elastic Beanstalk, Azure App Service and Google App Engine**
3. SaaS
	- Cloud based product, managed and run by the cloud provider
	- Apps that work over internet
	- Like **Google Workspace, Office 365, Salesforce**
