##### Content
1. Private Cloud
	- Complete control over infra
	- Enhanced security
	- Tailored to meet specific business needs
	- Like VMware, RedHat, OpenStack
	- Doesn't have to be in the company's location, but should be accessed by only that company
2. Public Cloud
	- Like AWS, offers: scalability, flexibility, cost-effectiveness, reliability, security and global accessibility.
3. Hybrid Cloud
	- Sensitive assets are in private cloud
	- Public / cost-effective assets are in public cloud
4. Multi Cloud
	- Using more than a cloud (AWS + GCP etc)
5. Community Cloud
	- More than an Entity co-operating a private cloud
