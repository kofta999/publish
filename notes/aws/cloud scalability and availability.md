##### Content
**Scalability:** ability of on app or system to handle increase loads by scaling up (vertical) or out (horizontal / elasticity)

**Elasticity:** In a scalable system, it refers to automatic scaling based on the load, enabling a pay-per-use model

**Agility:** implies that new IT resources can be provisioned quickly, minimizing time to availability from weeks to mins 

**High Availability:** ensuring that systems remain operational and accessible despite failures, focusing on minimizing downtime

For AWS:
Vertical Scaling: increase instance size

Horizontal Scaling: Increase number of instances

High Availability: Run instances of the same app across multiple AZs, and use ASG and LBs
