## **AWS DataSync**
- **Purpose**: Facilitates the transfer of large amounts of data from on-premises to AWS.
- **Key Features**:
  - Supports synchronization with AWS storage services like S3, EFS, and FSx for Windows.
  - Offers scheduled replication tasks with incremental updates after the initial full load.
- **Use Case**: Ideal for large-scale data migration and ongoing synchronization between on-premises and AWS environments.

---

## **AWS Application Discovery Service**
- **Purpose**: Helps plan migration projects by collecting data from on-premises data centers.
- **Key Features**:
  - **Agentless Discovery**: Captures VM inventory, configuration, and performance history.
  - **Agent-Based Discovery**: Provides detailed system configuration, performance, running processes, and network connections.
  - Data is viewable in AWS Migration Hub.
- **Use Case**: Assists in assessing and planning migrations by providing a comprehensive view of on-premises environments.

 

## **AWS Application Migration Service (MGN)**
- **Purpose**: Simplifies migrating applications to AWS using a lift-and-shift (rehost) approach.
- **Key Features**:
  - Converts physical, virtual, and cloud-based servers to run natively on AWS.
  - Supports a wide range of platforms, operating systems, and databases.
  - Minimizes downtime and reduces migration costs.
- **Use Case**: Ideal for businesses looking to migrate applications to AWS with minimal disruption.

---

## **AWS Migration Evaluator**
- **Purpose**: Assists in creating a data-driven business case for migrating to AWS.
- **Key Features**:
  - Provides a detailed view of the current on-premises environment.
  - Uses an Agentless Collector for broad-based discovery, capturing server dependencies and on-premises footprint.
  - Analyzes the current state, defines the target state, and helps develop a migration plan.
- **Use Case**: Helps organizations assess the feasibility and benefits of migrating to AWS.

---

## **AWS Migration Hub**
- **Purpose**: Central repository for collecting and tracking migration data.
- **Key Features**:
  - Accelerates migration to AWS and automates lift-and-shift processes.
  - Provides pre-built templates for migrating enterprise applications (e.g., SAP, Microsoft SQL Server).
  - Tracks migration status updates from AWS Application Migration Service (MGN).
- **Use Case**: Simplifies and centralizes the migration process for large-scale projects.
