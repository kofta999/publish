##### Content
#### Elastic Container Service (ECS)
- Allows you to launch docker containers on AWS
- You're responsible for provisioning and maintaining infra
- AWS takes care of starting and stopping containers for you

#### Fargate
- Used to launch containers on AWS without provisioning infra (serverless service)
- Simplifies the deployment process

#### Elastic Container Registry (ECR)
- A private docker registry on AWS
- Used to store your docker images securely, allowing them to be easily accessed by Fargate and ECS
