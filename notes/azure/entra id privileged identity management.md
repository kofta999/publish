### Privileged Identity Management (PIM)
Just-in-Time (JIT) elevation for privileged roles.

### Key Concepts
- Elevation: Users are "Eligible" for a role and must "Activate" it to use it. Can also work for groups
- Time-Bound: Activation is for a limited window (e.g., 4 hours).
- **Entra ID P2 Feature:** Required for both the admin and the eligible users.
- Integrated with Azure Portal IAM for managing both Entra and Azure Resource (ARM) roles.
