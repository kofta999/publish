##### Content

#### Object Storage
- Uses Object Storage Devices (OSDs)
- Accessible through APIs
- OSDs aren't hierarchical (files and directories) but it's a flat address space where all objects exist at the same level, and one object cannot be placed inside another object. This allows billions of objects to be stored in a single namespace

##### Object Components
- Object data
- Unique Object ID
- Metadata (Required, consists of access rights, creation, access timestamps)
- User-defined Attributes 

##### OSD Components
- OSD nodes (controllers)
- Internal Network
- Storage
