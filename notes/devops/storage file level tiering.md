##### File Storage Tiering
- Moving files from higher to lower tiers
- Tiers are defined based on cost, performance and availability
- Uses a policy-engine to determine which files should move to lower tiers

**Note:** Stub Files are files that contain the original file's metadata and a pointer to its location on T2/T3 storage
