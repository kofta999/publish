##### Content
**AWS CAF** assists in creating and executing a comprehensive plan for digital transformation using AWS
- Developed by AWS pros
- Uses AWS best practices and insights

![[Pasted image 20250330174223.png]]

It's not restricted to AWS, gives an action plan to transform to the cloud.

### Components
- Business Outcomes: results from cloud adoption
- Transformation Domains: use cases of cloud powered change focused on business outcomes (Technology -> Process -> Organization -> Product)
- Foundational Capabilities: best practice guidance to help improving cloud readiness
- Transformation Phases: [[aws caf steps]]

### Goals
- Identify and prioritize transformation opportunities
- Evaluate and improve cloud readiness
- Iteratively evolve transformation roadmaps

### Transformation Domains
- Technology: how to use cloud to migrate and modernize legacy infra, apps, data and analytics
- Process: digitizing, automating, and optimizing your business operations
- Organizational: reimagining business and technology team orchestration
- Product: reimagining a business model by creating new value propositions (products, services) and revenue models

### Perspectives
1. **Business**
	- Aligns business and IT needs
	- Maps IT investments to business results
2. **People**
	- Plan management
	- Managing people's roles depends on how much automation you're achieving
	- A bridge between tech and business
3. **Governance**
	- Managing investments by talking to ppl like project managers
	- Managing licenses
4. **Platform**
	- Resource provisioning
	- Using code practices (IaC)
	- Utilize architecture standards
5. **Security**
	- Managing access and auth (principle of least privilege)
	- Ensure using data encryption in suited parts of the system
	- Align security and compliance with current requirements
6. **Operations**
	- Monitoring system health
	- Managing scaling (auto-scaling)
	- Managing CI/CD
	- Logging for insights
	- Checking if we met business needs
