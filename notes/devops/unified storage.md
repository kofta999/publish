#### Unified Storage
- Combines different storage types into a single system (Block, File, Object)
- Most storage boxes are actually unified, but needs a license to unlock NFS / Object storage
- Manageable though a single management interface
- For block access, the controller configures LUNs and presents them to servers
- For NAS clients, the controller configures LUNs, creates a file system with NFS / CIFS etc and export the share to the clients
